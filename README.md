# GRIN

GRIN is a social communication platform in development, inspired by the best ideas across messaging and social networks.

## Current milestone

v0.1 establishes the mobile-first chat experience and frontend foundation. The next layer will connect Supabase Auth, Postgres, Realtime and Storage for real accounts and persistent conversations.

## Stack

- React + Vite
- Supabase (planned integration)
- Cloudflare deployment

## Development

npm install

npm run dev
